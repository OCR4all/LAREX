## Ongoing review

When adding a page family or changing a consequential control, update its guide and this map in the same change. Coverage means a discoverable explanation exists; it does not imply all edge cases have an illustrated procedure. Keep the implementation source as authority and add a small tested example when a workflow changes.

No new application runtime was provisioned for this audit. The first-project tutorial and all guides are source-checked; live sign-in, editing, remote processing, training, and restoration require a suitable running application and test data to validate end to end.
