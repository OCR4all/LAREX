# Workspace search

Workspace search finds indexed transcription across accessible projects in the selected workspace. It is useful for repeated OCR errors, recurring names, and returning to a page whose text you remember.

## Run a search

1. Select the intended workspace and open workspace search from navigation or the command center.
2. Enter at least **two characters**.
3. Choose a matching mode and inspect the result snippets.
4. Open a result to continue review in the editor, with the search term passed into its text-review context.

| Match mode | Use |
| --- | --- |
| Auto | Start with normal matching and allow automatic fuzzy expansion when applicable. The interface indicates when results were expanded. |
| Exact | Search without fuzzy expansion when you need the entered form. |
| Fuzzy | Find approximate forms, useful for recognition errors or uncertain spelling. |

Exact here refers to the search matching mode; it is not a promise of case-sensitive byte-for-byte XML matching. Use the displayed snippets to confirm the result.

## Choose a result view

- **Hits** lists individual matches for focused review.
- **Clustered** groups matching pages by project, useful when investigating a whole document or collection.

More results load as you scroll. Check the project/page identity and transcription context before changing a repeated form; the same spelling can be correct in one source and wrong in another.

## Correct a recurring error

Search for the suspected form, inspect a result, correct the ground-truth transcription, and save. Return to search to review other occurrences. Recognition alternatives may still contain the old form, depending on what was corrected and which indexed variants participate in search.

Normalization profiles are used by specific review operations; assigning one does not imply that workspace search rewrites its index into that normalized form.

## If expected text is missing

Check the workspace, query length, matching mode, and saved XML content. Pages without text or with pending/failed indexing may not appear. Allow indexing to finish after edits, imports, or Action results, then retry.

If the index stays stale, give an administrator the project/page and visible index state. Administrators can inspect and rebuild the index. See [Troubleshooting](/user-guide/troubleshooting#text-lines-or-search-results-seem-missing).
