# Keyboard Shortcuts

Keyboard shortcuts keep annotation and text correction work moving. The in-app shortcut dialog is the authoritative reference for the current editor state.

Press `?` in the editor to open or close the shortcut dialog.

## Common Shortcuts

| Shortcut | Use |
| --- | --- |
| `Ctrl/Cmd+S` | Save the active page. |
| `?` | Open the keyboard shortcut dialog. |
| Hold `Alt`/`Option` | Show labels and exact PAGE types over visible regions, text lines, and baselines. |
| `Escape` | Cancel the active transient tool, including Action target picking. |
| `Ctrl/Cmd+F` | Search in text or raw XML editor contexts that support find. |
| `Ctrl/Cmd+H` | Open replace in raw XML editor contexts that support it. |

Some shortcuts depend on the active mode, focused field, selected tool, and operating system.

## Views and common layout tools

These are default bindings; your saved customizations may differ.

| Shortcut | Action |
| --- | --- |
| `1`, `2`, `3` | Layout · Hierarchy, Text lines, Baselines. |
| `4`, `5`, `6` | Text · Canvas, List, Full text. |
| `V` / `G` | Select / move tool. |
| `P` / `R` | Region polygon / rectangle. |
| `T` / `Shift+T` | Textline polygon / rectangle. |
| `B` | Baseline tool. |
| `C` / `Shift+C` / `Alt+C` | Cut line / polygon / rectangle. |
| `M` | Merge selection. |
| `Ctrl/Cmd+Z` | Undo. |
| `Ctrl/Cmd+Shift+Z` or `Ctrl/Cmd+Y` | Redo. |

## Customize bindings

Open `?`, search for a command, and choose **Customize** from its menu. Capture the desired key combination, review conflicts, then save. Multiple bindings are supported for a command. Browser/operating-system reserved combinations and conflicting command bindings are rejected.

Use **Reset** to restore one command or **Reset all** for the default set. If a reset would conflict with another customized command, resolve that conflict or reset the full set. Hold gestures such as Alt/Option labels are separate from configurable command shortcuts.

The dialog reflects your active saved preferences. Check it when a documented default does not work.

## Avoiding Mistakes

- Check the active tool before using shape-edit shortcuts.
- Save after completing a coherent edit.
- Do not run Actions from the editor until important unsaved PAGE XML changes are saved.
- If a shortcut seems inactive, click the editor surface or relevant panel and try again.
