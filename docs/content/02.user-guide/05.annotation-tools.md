# Annotation Tools

Annotation tools edit the PAGE XML structures shown on the canvas. Use them to create and correct regions, textlines, baselines, reading order, and relations.

## Choose The Right Mode

| Work | Use |
| --- | --- |
| Create or reshape layout areas | Layout → Hierarchy |
| Focus on textline geometry | Layout → Text lines |
| Focus on baselines | Layout → Baselines |
| Correct text on the page image | Text → Canvas |
| Search, sort, and review textlines | Text → List |
| Read continuous transcription beside the page | Text → Full text |

Choose the complete mode and view from the grouped toolbar selector before starting a tool-heavy task. It keeps the canvas and sidebars focused on the information you need.

## Draw Shapes

LAREX supports polygon and rectangle drawing where the PAGE element type allows it.

Basic flow:

1. Choose the drawing tool.
2. Select the target element type when needed.
3. Draw on the canvas.
4. Double-click to finish polygon or polyline tools.
5. Save the page when the annotation is correct.

Use rectangles for fast regular shapes and polygons for irregular historical layouts.

## Edit Existing Shapes

Select an element on the canvas or in the structure panel. Depending on the element, you can move vertices, reshape polygons, adjust baselines, update metadata, or change labels.

The structure panel is useful when overlapping elements make direct canvas selection difficult.

## Cut And Merge

Cut tools split existing layout structures. Merge combines compatible structures when an earlier split or processor result created too many elements.

Before using destructive geometry tools:

- zoom in enough to verify the target
- confirm the selected element in the structure panel
- save after a coherent correction, not after every click

## Reading Order And Relations

Reading order describes sequence. Relations describe explicit links between PAGE elements.

Use the reading order panel when text flow matters for downstream OCR/HTR, exports, or review. Use the relations panel when your project needs semantic links between elements, such as source/target region relationships.

## Set reading order

1. Open the **Reading Order** panel in layout mode.
2. Inspect the current order and the **Available** list of regions not yet included.
3. Add the intended regions, then drag entries into the reading sequence.
4. Select related entries and use **Ordered** for a sequence or **Unordered** for a group with no defined sequence. Expand groups to inspect their contents; dissolve a group when its grouping is no longer useful.
5. Turn on the reading-order overlay and inspect arrows, numbers, group bounds, and labels against the page.
6. Save and check the result before relying on flattened text exports.

Canvas selection and reading-order list selection have different gestures. Within the order list, Ctrl/Cmd-click toggles items and Shift-click selects a range. Removing a reference from the order does not mean deleting that region's geometry.

## Create a region relation

1. Open **Relations** and start a relation draft.
2. Choose its type and source/target regions, or use **Pick On Canvas** to select endpoints.
3. Leave the relation ID empty to generate one, or supply the intended ID.
4. Add optional labels, custom information, or comments where needed, then choose **Create Now**.
5. Inspect the relation overlay, save, and verify that the endpoints identify the intended regions.

A relation records a link between regions. It does not replace the page's reading-order sequence.

## Edit metadata at the correct level

The **Metadata** panel changes with the selected element. Clear the selection for document/page metadata; select a region or textline for its fields. Review the element identifier before applying edits.

Available fields depend on PAGE element type. They include reading direction/orientation, comments, language and script information, label groups, alternative images, and typed user attributes. A label group can carry external model/ID information; a user attribute has a name, optional description/type, and value.

Apply the metadata edit and save the page. Use the raw XML editor for XML inspection and schema validation, and [version comparison](/user-guide/history-and-collaboration#compare-and-restore-a-version) when reviewing an earlier saved state.

## Actions And Targeted Processing

The Action wand can use selected page structures as processor targets. Region and textline Actions are useful when a processor should re-run on only part of a page.

Targeted Actions still dispatch full page files. The processor receives selected region or textline IDs and returns normal PAGE XML. LAREX imports only the selected target scope.
