# Label Sets

Label sets define which annotation labels users can choose in the editor. They keep PAGE XML structures consistent across projects and reduce cleanup after manual annotation or processor import.

## What Labels Control

Labels describe PAGE regions and their structural subtypes. A label set can make project-specific region vocabularies available without changing the editor code.

Good labels are:

- specific enough to be useful
- short enough to scan in menus
- stable across a project
- documented for annotators

## Create A Label Set

1. Open **Label Sets** from the toolkit.
2. Create a new label set.
3. Add the labels your project needs.
4. Drag labels into the order annotators should see in the editor context menu.
5. Optionally use the circle-check action to mark one label as the default.
6. Assign the label set as a workspace preset or project setting.

Use a small set first. It is easier to add specialized labels later than to clean up inconsistent early annotation.

## Use Labels In The Editor

When a project has a label set, drawing and editing tools expose the configured labels. Annotators should choose the label that best describes the layout element, not the later processing step.

New regions use the label set's configured default label. If no default is configured, they use the first label in the saved label order.

If a processor creates or updates PAGE XML, imported structures should still fit the project label vocabulary. Review processor output when introducing a new Action.

## Label Set Changes

Changing a label set affects future choices in the editor. It does not automatically rewrite every existing PAGE XML file. Plan renames or removals carefully and document the intended migration for curators.
