# Virtual Keyboard

Virtual keyboards make project-specific characters available during text correction. They are useful for historical printings, diacritics, symbols, abbreviations, and scripts that are inconvenient to type on a standard keyboard.

## When To Use It

Use a virtual keyboard when annotators repeatedly need characters that are:

- missing from their physical keyboard
- hard to remember as Unicode input
- easy to confuse with similar characters
- specific to a project, language, or source collection

## Configure A Keyboard

Curators can create and edit virtual keyboard resources from the toolkit. Add characters or groups in the order annotators should see them.

Practical tips:

- Put the most common characters first.
- Group visually similar characters carefully.
- Avoid adding every possible Unicode character; keep the resource project-specific.
- Include characters exactly as they should be inserted into transcription text.

## Use In Text Mode

When a project has a virtual keyboard assigned, the text sidebar can show keyboard actions. Click a character to insert it into the active text field or correction workflow.

The virtual keyboard supports consistency, but it does not replace proofreading. Annotators still need to verify that inserted characters match the source image.
