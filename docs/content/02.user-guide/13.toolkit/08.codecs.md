# Codecs

A codec is an inventory of characters accepted by a project's transcription workflow. Use one to detect unexpected glyphs or prepare a known character set for ground-truth work. A codec does not recognize text or replace a model.

## Create and assign a codec

1. Open **Codecs** in the workspace toolkit and create a resource.
2. Name it for its purpose or transcription convention.
3. Add characters directly or use **Pick Glyph**. Review visually similar characters carefully.
4. Save, then assign it to a project or as a workspace project default.

Curators manage the inventory. A project's codec controls the review warnings; characters outside it need review rather than automatic deletion.

## Generate from sources

Choose **Generate codec from sources**. Select projects and, if needed, individual pages. Use project/page tags to narrow the source selection.

Select **All indexed variants** or **Specific index / unindexed**. For the latter, choose an index or **Unindexed only**. Choose whether to include whitespace, then create a new codec or append to an existing one.

**Check:** review the extracted inventory before using it as a policy. Generating from uncorrected recognition can include OCR errors, so it describes the selected source text rather than proving those characters should be accepted.

## Validate coverage

Choose **Validate codec against sources**, select the projects/pages and variant scope, and run the check. Results show missing characters and the affected pages/projects.

For each unexpected character, compare it with the source image. Correct a transcription error, or extend the codec when the character is legitimate. Validate again using the same scope after saving and indexing corrections.

In text mode, the codec panel and highlighting help review unsupported characters while correcting lines. See [Text review](/user-guide/text-review).

## Move a codec between workspaces

Export/import a toolkit package or use the codec's sharing action. Package import creates or resolves a workspace resource; it is different from assigning an existing codec to another project in the same workspace. See [Toolkit packages](/user-guide/toolkit/overview#export-import-and-share-resources).
