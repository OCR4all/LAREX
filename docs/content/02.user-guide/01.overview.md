# User guide

Use this guide to complete a workflow, then consult the linked references when you need a particular control. New to LAREX? Start with [Your first project](/getting-started/first-project) and [Core concepts](/getting-started/concepts).

## The working sequence

| Stage | What you achieve | Guide |
| --- | --- | --- |
| Organize | Put the material in the right workspace and set team permissions. | [Workspace and library](/user-guide/workspace-library) |
| Import | Create a project, add images/XML/PDFs or IIIF material, and resolve conflicts. | [Projects](/user-guide/projects) |
| Annotate | Draw or correct page structure and choose the right editor view. | [Editor interface](/user-guide/editor-interface), [annotation tools](/user-guide/annotation-tools) |
| Correct | Compare transcriptions with images, handle text variants, and use review resources. | [Text correction and review](/user-guide/text-review) |
| Coordinate | Share edit access, compare versions, and complete page Tasks. | [Collaboration and history](/user-guide/history-and-collaboration), [Assignments](/user-guide/tasks) |
| Find | Locate transcription across the workspace and reopen a matching line. | [Workspace search](/user-guide/workspace-search) |
| Deliver | Choose an export, create a release, or transfer work. | [Exports, releases, and sharing](/user-guide/exports-and-sharing) |
| Reuse | Curate pages into a dataset, choose splits, and freeze a release. | [Datasets and releases](/user-guide/datasets) |
| Automate | Run assigned processors and review their results. | [LAREX Actions](/user-guide/larex-actions) |

## Configure consistent work

Curators can assign [toolkit resources](/user-guide/toolkit/overview) to projects or workspace defaults. Start with the resources your workflow needs: labels for layout, a keyboard for special characters, a codec for allowed characters, or a dictionary for token review. Add normalization and regex validation rules only after testing them on representative text.

[Administrators](/user-guide/admin-dashboard/overview) manage instance-wide users, storage, imports, backups, search indexes, and Action definitions. [Account settings](/user-guide/account-and-notifications) cover your own profile, invitations, transfers, and notifications.
