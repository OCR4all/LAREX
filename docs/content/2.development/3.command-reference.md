# Command Reference

All root commands are run as `task <name>` unless noted otherwise.

## Common Task Commands

| Command | Description |
|---------|-------------|
| `task setup` | Install dependencies and start dev infrastructure |
| `task install` | Install frontend and theme dependencies |
| `task dev` | Print the local dev startup flow |
| `task test` | Run backend and frontend checks |
| `task build` | Build backend, frontend, and theme |
| `task clean` | Remove build artifacts |

## Docker Tasks

### Local dev

| Command | Description |
|---------|-------------|
| `task docker:up` | Start the local dev compose stack |
| `task docker:up:build` | Rebuild and start the local dev stack |
| `task docker:down` | Stop the local dev stack |
| `task docker:down:clean` | Stop the local dev stack and remove volumes |
| `task docker:infra` | Start only local dev infrastructure |
| `task docker:logs` | View local dev logs |
| `task docker:logs:backend` | View backend logs |
| `task docker:logs:frontend` | View frontend logs |
| `task docker:ps` | Show local dev containers |

### Production-like and production

| Command | Description |
|---------|-------------|
| `task docker:prod:up` | Start the opinionated production stack |
| `task docker:prod:down` | Stop the opinionated production stack |
| `task docker:prod:logs` | View opinionated production logs |
| `task docker:prod:local:up` | Start local production-like services |
| `task docker:prod:local:down` | Stop local production-like services |
| `task docker:prod:local:logs` | View local production-like logs |
| `task docker:prod:external-keycloak:up` | Start production with external Keycloak |
| `task docker:prod:external-keycloak:down` | Stop production with external Keycloak |
| `task docker:prod:external-keycloak:logs` | View production logs for external Keycloak |
| `task docker:prod:nginx:up` | Start production with bundled Nginx |
| `task docker:prod:nginx:down` | Stop production with bundled Nginx |
| `task docker:prod:nginx:logs` | View production logs for bundled Nginx |

## Direct Docker Compose Commands

### Local dev

```bash
docker compose up -d
docker compose logs -f
docker compose down
```

### Local production-like

```bash
docker compose --env-file .env.prod.local \
  -f compose.prod.base.yaml \
  -f compose.prod.auth.bundled-keycloak.yaml \
  -f compose.prod.local.yaml \
  up -d
```

### Opinionated production

```bash
docker compose --env-file .env.prod \
  -f compose.prod.base.yaml \
  -f compose.prod.auth.bundled-keycloak.yaml \
  -f compose.prod.publish.localhost.yaml \
  up -d
```

### Production with external Keycloak

```bash
docker compose --env-file .env.prod \
  -f compose.prod.base.yaml \
  -f compose.prod.auth.external-keycloak.yaml \
  -f compose.prod.publish.localhost.yaml \
  up -d
```
