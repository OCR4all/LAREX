The Python [`larex-action-sdk`](https://github.com/OCR4all/larex-action-sdk)
provides typed inputs, HMAC dispatch verification, callback clients with retries,
result builders, cooperative cancellation, and an optional FastAPI adapter. It
requires Python 3.11+ and Pydantic 2.12+.

::warning
The SDK is pre-1.0. Its public API can still change before LAREX Actions and the
SDK are considered stable. Check the
[changelog](https://github.com/OCR4all/larex-action-sdk/blob/main/CHANGELOG.md)
before upgrading a processor.
::

## Install

For a FastAPI processor:

```bash
uv add "larex-action-sdk[fastapi]"
```

For framework-neutral usage:

```bash
uv add larex-action-sdk
```

## Protocol and capabilities

The protocol version is `1`. Features are negotiated through capabilities, not
inferred from a version number. LAREX advertises its capabilities in the dispatch
and pulled input; the processor advertises its own during preflight. The SDK
refuses to use an interface the server does not advertise, so a processor fails
early instead of silently losing data on an older LAREX.

| Capability | Enables | SDK error when the server lacks it |
| --- | --- | --- |
| `incrementalPageResults` | `ctx.submit_page_results()` | Submission refused before upload |
| `customFileResults` | `add_file_bytes()` / `add_file_path()` | `CustomFileResultsUnsupported` |
| `runReports` | Page outcomes, warnings, and `run_report=` | `RunReportsUnsupported` |
| `evaluationReports` | `ctx.complete_evaluation()` | `EvaluationReportsUnsupported` |
| `parameterValueDiscovery` | Processor-provided parameter values | Advertised by the processor only |

## What the SDK handles

- verifying `X-LAREX-Action-*` HMAC dispatch headers, timestamps, and nonces
- parsing typed dispatch and input payloads
- pulling input metadata and downloading image/XML files
- sending heartbeats, progress, and log lines
- checking cooperative cancellation and running cancellable subprocesses
- building result manifests and uploading result files
- submitting and acknowledging individual page results
- retrying transient callback failures
- keeping secrets out of model representations
