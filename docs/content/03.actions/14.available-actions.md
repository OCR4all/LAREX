LAREX does not include processors in the main application. This page lists public Actions that an administrator can deploy and register.

| Group | Maintained by |
| --- | --- |
| [Official](#official-actions) | The [OCR4all organization](https://github.com/OCR4all) on GitHub. |
| [Community](#community-actions) | Their own authors, in any other public repository. |

Built one that is missing? [Add it to the list](#contribute-an-action).

## Official Actions

All official Actions listed here are `PROCESSING` Actions. Check each repository for its current parameters, requirements, and deployment steps.

| Action | What it does | Targets | Returns |
| --- | --- | --- | --- |
| [Kraken Segmentation](https://github.com/OCR4all/larex-action-kraken) | Segments pages or selected regions with Kraken baseline segmentation. | `PAGE`, `REGION` | PAGE XML |
| [Line Segmentation](https://github.com/OCR4all/larex-action-line-segmentation) | Computes baselines and polygons for existing text regions, based on the ocropus algorithm. | `PAGE`, `REGION` | PAGE XML |
| [Ocropus NLBIN](https://github.com/OCR4all/larex-action-ocropus-nlbin) | Normalizes and binarizes page images with ocropus nlbin. | `PAGE` | Images |
| [PAGE XML Text + NER Export](https://github.com/OCR4all/larex-action-pagexml-ner) | Exports text in reading order and, optionally, named entities found with spaCy. | `PAGE` | Files |
| [SBB Binarization](https://github.com/OCR4all/larex-action-sbb-binarization) | Binarizes page images with an SBB binarization model. | `PAGE` | Images |

### Deployment notes

| Action | Container | Before you run it |
| --- | --- | --- |
| Kraken Segmentation | Published image; also a service in [`compose.actions.yaml`](/deployment/official-action-services) | Runs on CPU by default. `REGION` runs need existing PAGE XML. |
| Line Segmentation | Build from the repository | Needs binary images and PAGE XML with text regions. Run a binarization Action first if you have no binary images. |
| Ocropus NLBIN | Build from the repository | The supplied Compose file requests NVIDIA GPUs. |
| PAGE XML Text + NER Export | Published image | Needs PAGE XML. The included spaCy model is for English. |
| SBB Binarization | Build from the repository | Needs a model you provide. The supplied Compose file requests NVIDIA GPUs. |

After deploying a processor, follow [Admin Setup](/actions/admin-setup) to create its endpoint secret and register its definition. Replace the placeholder processor ID, endpoint URLs, and secret reference in the supplied definition first.

## Community Actions

::warning
Community Actions are not reviewed or supported by the LAREX maintainers. A processor receives the page images and PAGE XML of every run, so check its source and where it sends data before you deploy it. See [Security and Deployment](/actions/security-deployment).
::

No community Actions are listed yet. Yours can be the first.

## Contribute an Action

Share a processor that others could use, whatever it does: layout analysis, OCR/HTR, enrichment, exports, training, or evaluation. It can stay in your own repository.

::card-group
:::card{title="Build an Action" icon="i-lucide-hammer" to="https://github.com/OCR4all/larex-action-starter"}
Start from the template repository, which uses the Processor SDK.
:::

:::card{title="Add it to this page" icon="i-lucide-git-pull-request" to="https://github.com/OCR4all/LAREX/edit/dev/docs/content/03.actions/14.available-actions.md"}
Edit this page on GitHub and open a pull request into `dev`.
:::

:::card{title="Suggest an Action" icon="i-lucide-message-square-plus" to="https://github.com/OCR4all/LAREX/issues/new?title=docs%28actions%29%3A%20list%20ACTION%20NAME&body=Repository%3A%0AWhat%20it%20does%3A%0AKind%20and%20targets%3A%0AReturns%3A%0AMaintainer%3A"}
Open an issue with the repository link, and a maintainer can add it.
:::
::

### What a listed Action needs

- A public repository with a license.
- An Action definition that matches the [YAML Reference](/actions/yaml-reference).
- A README that explains what the Action does, how to deploy it, and which models or hardware it needs.
- A way to report problems, such as an issue tracker.

### Table format

The first entry replaces the "No community Actions" sentence with this table. Later entries add one row, in alphabetical order:

```md
| Action | What it does | Kind | Targets | Returns | Maintainer |
| --- | --- | --- | --- | --- | --- |
| [Action name](https://github.com/owner/repository) | One sentence. | `PROCESSING` | `PAGE` | PAGE XML | [owner](https://github.com/owner) |
```

To improve an official Action, open an issue or pull request in its own repository.
