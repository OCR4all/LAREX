# Introduction

LAREX is a web application for managing facsimile collections, editing PAGE XML annotations, and coordinating OCR/HTR or layout-processing workflows. It is built for projects where human review and processor output need to live together: curators organize material, annotators correct and enrich pages, and external processors can be dispatched through LAREX Actions.

## What LAREX Manages

LAREX organizes work around workspaces and projects.

- A **workspace** contains projects, members, presets, and shared resources.
- A **project** contains pages, page images, PAGE XML files, metadata, tasks, and project-level settings.
- The **editor** is where users inspect page images, draw or correct regions/textlines/baselines, edit text, review metadata, and save PAGE XML.
- **Toolkit resources** such as tag sets, label sets, dictionaries, normalization profiles, validation rulesets, codecs, and virtual keyboards keep review workflows consistent.
- **LAREX Actions** connect projects to external processors. An Action can receive selected page data, run outside LAREX, and return XML or image outputs for import.
- The **Admin Dashboard** gives global administrators instance-wide controls for users, workspaces, quotas, storage cleanup, server-side imports, backups, monitoring, and Action operations.

## Architecture

LAREX is split into independently understandable services:

```text
Browser
  |
  | same-origin /api/*
  v
Nuxt frontend
  |
  | internal backend API
  v
Spring Boot backend ---- PostgreSQL
  |
  | OAuth2 / OIDC
  v
Keycloak

Optional:
  - docs Nuxt app on the docs host
  - external LAREX Action processors
  - Traefik for local and production-like routing
```

The frontend uses a Backend-for-Frontend pattern. Browser requests go to the Nuxt app, and Nuxt server routes forward authenticated API calls to the Spring Boot backend. The backend remains authoritative for permissions, validation, storage, Action dispatch, and import behavior.

## Current Stack

| Area | Main technology |
| --- | --- |
| Frontend | Nuxt 4, Vue, Nuxt UI, Pinia, Tailwind CSS |
| Backend | Spring Boot 4, Java 25, PostgreSQL, Flyway |
| Authentication | Keycloak 26.x with OAuth2/OIDC |
| Docs | Independent Nuxt Content app with Nuxt UI |
| Local orchestration | Taskfile, Docker Compose, Traefik |
| Processor SDK | `larex-action-sdk` for Python 3.11+ |
