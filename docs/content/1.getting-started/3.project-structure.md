# Project Structure

## Root Directory

```text
larex/
├── .github/                               # GitHub workflows
├── backend/                               # Spring Boot backend
├── frontend/                              # Nuxt frontend
├── keycloak-theme/                        # Keycloak login theme
├── docs/                                  # Documentation site
├── config/                                # Runtime config artifacts
├── deployment/                            # Env examples and Nginx assets
├── scripts/                               # Utility scripts
├── traefik/                               # Shared local Traefik config
├── compose.yaml                           # Local dev stack
├── compose.actions.yaml                   # Optional official Action processor services
├── compose.prod.base.yaml                 # Shared production runtime services
├── compose.prod.auth.bundled-keycloak.yaml
├── compose.prod.auth.external-keycloak.yaml
├── compose.prod.publish.localhost.yaml    # Loopback publishing for production
├── compose.prod.local.yaml                # Local production-like overlay
├── compose.prod.nginx.yaml                # Optional production Nginx overlay
├── Taskfile.yml
├── VERSION
└── README.md
```

## Deployment Assets

`deployment/` now contains:

- `actions/` with production-ready Action definition YAML files
- `env/` with the supported core and optional Action service env examples
- `nginx/templates/` with the optional production Nginx template
