# Keyboard Shortcuts

Keyboard shortcuts keep annotation and text correction work moving. The in-app shortcut dialog is the authoritative reference for the current editor state.

Press `?` in the editor to open or close the shortcut dialog.

## Common Shortcuts

| Shortcut | Use |
| --- | --- |
| `Ctrl/Cmd+S` | Save the active page. |
| `?` | Open the keyboard shortcut dialog. |
| Hold `Alt`/`Option` | Show labels and exact PAGE types over visible regions, text lines, and baselines. |
| `Escape` | Cancel the active transient tool, including Action target picking. |
| `Ctrl/Cmd+F` | Search in text or raw XML editor contexts that support find. |
| `Ctrl/Cmd+H` | Open replace in raw XML editor contexts that support it. |

Some shortcuts depend on the active mode, focused field, selected tool, and operating system.

## Avoiding Mistakes

- Check the active tool before using shape-edit shortcuts.
- Save after completing a coherent edit.
- Do not run Actions from the editor until important unsaved PAGE XML changes are saved.
- If a shortcut seems inactive, click the editor surface or relevant panel and try again.
