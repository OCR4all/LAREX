# Workspace and Library

This page covers workspace management and the main project library view.

## Workspaces

### Workspace Types

| Type | Description |
|------|-------------|
| Personal workspace | Created automatically for each user; single-user workspace |
| Team workspace | User-created collaborative workspace with member management |

### Creating a Team Workspace

1. Open **Workspaces**.
2. Click **New Workspace**.
3. Enter name and optional description.
4. Optionally pre-invite users and set each invite as `Member` or `Administrator`.
5. Create the workspace.

Personal workspaces are not created manually.

### Switching Workspaces

- Use the workspace selector and select the target workspace.
- The library updates to projects from that workspace.

## Roles and Permissions

### Workspace Member Roles

Team workspace membership roles are:

- `ADMINISTRATOR`
- `MEMBER`

The workspace owner is also shown in the UI as `OWNER`.

### Global Admin Role

`GLOBAL_ADMIN` is a separate global role (used for admin-only sections), not a workspace member role.

### Member Management

For team workspaces, administrators can:

- Invite users
- Change member roles (`Administrator` / `Member`)
- Remove members

Path: **Workspace Settings → Members**.

## Library Overview

The Library (`/`) lists projects for the selected workspace.

### Main Capabilities

- Project search
- Tag filtering (multi-select)
- Tag filter operator (`Match any` / `Match all`)
- Starred filter
- Sorting by multiple columns
- Pagination
- Row actions (open/edit/share/delete)
- Multi-select for batch codec actions

### Library Columns

| Column | Description |
|--------|-------------|
| Select | Row checkbox for multi-select |
| Name | Project link |
| Description | Project description |
| Tags | Resolved tags or raw tags |
| Pages | Page count |
| Storage | Formatted project storage |
| Created | Creation timestamp |
| Updated | Last update timestamp |
| Actions | Row action menu |

## Creating and Editing Projects

### Create Project

From **New Project**, you can set:

- Name (required)
- Description
- Tags
- Tag Set preset
- Codec preset
- Label Set preset
- Default GT index
- Default recognition indices

### Edit Project

From project actions, you can update:

- Name/description
- Tags and tag set
- Codec and label set
- Default text-index settings

## Project Actions

### Share Project

Project sharing is handled as a transfer request to another workspace:

- Transfer type: `MOVE` or `COPY`
- Optional message
- Request goes through workspace transfer flow

### Other Actions

- Open project
- Edit
- Delete

### Batch Actions (selected projects)

- Generate codec from selected project scope
- Validate codec against selected project scope

## Storage

- Project rows show per-project storage usage.
- Workspace-level storage usage is available in **Workspace Settings**.
