# Keyboard Shortcuts

This list reflects shortcuts currently wired in the app.

`Ctrl` on Windows/Linux corresponds to `⌘` on macOS for `Ctrl/Cmd` combos.

## Global Editor

### General

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open command center |
| `Shift + ?` | Toggle keyboard shortcuts dialog |
| `Ctrl/Cmd + S` | Save active page |
| `Alt + W` | Close active page tab |

### Undo/Redo

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| `Ctrl/Cmd + Y` | Redo |

### Tool Modes

| Shortcut | Action |
|----------|--------|
| `V` | Select mode |
| `G` | Move mode |
| `P` | Region polygon |
| `R` | Region rectangle |
| `T` | Textline polygon |
| `Shift + T` | Textline rectangle |
| `B` | Baseline |
| `C` | Cut line |
| `Shift + C` | Cut polygon |
| `Alt + C` | Cut rectangle |
| `M` | Merge selected (when valid) |

### View and UI Modes

| Shortcut | Action |
|----------|--------|
| `1` | Default view |
| `2` | Textline view |
| `3` | Baseline view |
| `Space` | Reset zoom and pan |
| `L` | Layout mode |
| `Shift + L` | Text mode |
| `K` | Toggle virtual keyboard mode |

### Selection and Navigation

| Shortcut | Action |
|----------|--------|
| `Esc` | Cancel drawing / clear selection |
| `Ctrl/Cmd + A` | Select all selectable polygons |
| `Delete` / `Backspace` | Delete selected elements |
| `Tab` | Next selectable element |
| `Shift + Tab` | Previous selectable element |
| `Arrow Down` | Next selectable element |
| `Arrow Up` | Previous selectable element |

### Panels and Page Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + \` | Toggle left sidebar |
| `Ctrl/Cmd + Shift + \` | Toggle right sidebar |
| `Ctrl/Cmd + Arrow Down` | Next page |
| `Ctrl/Cmd + Arrow Up` | Previous page |
| `Ctrl/Cmd + Ctrl + Arrow Down` | Close current tab and open next page |
| `Ctrl/Cmd + Ctrl + Arrow Up` | Close current tab and open previous page |

## Text View Specific

These are active in the textline list/text editing view.

| Shortcut | Action |
|----------|--------|
| `Tab` | Cycle to next text variant field |
| `Esc` | Blur active text field |
| `Alt + Enter` | Jump to next field with same index |
| `Ctrl/Cmd + Alt + G` | Create GT from selected textline recognition |

## Notes

- Most editor shortcuts are ignored while typing in inputs/textareas.
- Some actions are context-dependent (for example merge requires a valid multi-selection).
