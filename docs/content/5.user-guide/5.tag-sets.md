# Tag Sets

Tag sets define hierarchical tags used to categorize projects and pages.

## Tag Sets vs Labels

| Aspect | Tag Sets | Labels |
|--------|----------|--------|
| Scope | Dashboard data (projects/pages) | Editor annotation structure |
| Use Case | Categorization and filtering | Export/document structure |
| Applied To | Projects and pages | Regions/textline structures |

## Accessing Tag Sets

1. Open the left dashboard sidebar.
2. Go to **Tags** (`/tag-sets`).

## Tag Set List

The list view includes:

- Search
- Tag filter (multi-select)
- Filter operator: `Match any (OR)` / `Match all (AND)`
- Sorting (name/description)
- Pagination
- Row actions: edit, delete

## Creating and Editing Tag Sets

1. Click **New Tag Set**.
2. Build or edit the tag tree.
3. Open **Tag Set Settings** and set name, description, and meta tags.
4. Save.

## Builder Capabilities

In the tag-set builder, you can:

- Add root tags
- Add child tags
- Duplicate tags (with children)
- Delete tags (with confirmation)
- Edit tag title, description, and color
- Move tags up/down within sibling order
- Search the tag tree
- Expand/collapse tree sections
- Auto-optimize colors

Validation prevents saving when there are configuration errors (for example empty or duplicate tag titles).

## Applying Tags

### Project Tags

1. Open a project row action in the Library.
2. Choose **Edit**.
3. Set project tags.
4. Save.

### Page Tags

1. Open a project.
2. Use a page row action **Edit**.
3. Set page tags.
4. Save.

## Import and Export

From the builder header:

- Import tag-set package JSON (`toolkit/import`)
- Export as toolkit package (`toolkit/export`)

For new/unsaved tag sets, local JSON export is available from current builder state.

## Deleting Tag Sets

Deleting a tag set removes the tag-set reference from projects that used it.
