# Workspace Search

Workspace Search lets you search persisted transcription text across all accessible projects in the currently selected workspace.

## How to Open It

You can reach workspace search in two ways:

- Use the command center (`Ctrl/Cmd + K`) and start typing a transcription term.
- Select **See all text results** from the `Text Hits` group to open the full search page.

The full search page is available at `/search`.

## Scope

Workspace search is scoped to the currently selected workspace.

It searches:

- persisted indexed transcription text
- the primary indexed text variant used for workspace/page filtering

It does not search:

- unsaved editor changes
- every OCR/HTR alternate at once
- other workspaces

## Result Views

### Hits

`Hits` shows a flat ranked list of search matches.

Each result includes:

- image cutout preview
- highlighted text snippet
- page name
- project name
- match type badge
- actions to open the page in the editor or open the project

### Clustered

`Clustered` groups the same hit set by:

1. project
2. page

Use this view when you want to inspect where a query occurs across a project before opening individual pages.

## Match Modes

### Auto

`Auto` starts with normal text search and falls back to fuzzy expansion when the result set is small.

### Exact

`Exact` runs normal full-text search only.

### Fuzzy

`Fuzzy` expands terms through the indexed workspace lexicon to find near matches.

Useful for:

- OCR/HTR spelling variation
- minor transcription differences
- misspelled search terms

Notes:

- very short tokens are not useful fuzzy candidates
- quoted phrase queries stay phrase-oriented rather than being fuzzed token-by-token

## Search Input Behavior

- Enter at least two characters to run workspace search.
- Quoted phrases can be used for more exact phrase-like matching.
- Results load progressively as you scroll.

## Opening Results in the Editor

`Open in Editor` opens the target page directly in:

- `Text` mode
- `Textline` text view

It also carries the search term into the editor text filter so you can continue reviewing the hit in context.

The same behavior applies when opening a workspace text hit directly from the command center.

## Result Previews

Search previews are server-generated cutouts from the page image.

They highlight the matched text line or region so the preview is visually tied to the hit rather than showing only the full page.

## When Results Look Missing or Stale

Workspace search depends on the persisted search index.

If results seem incomplete or outdated, rebuild the search index from:

- **Admin → Search Index**

Typical cases where a rebuild helps:

- older data imported before search indexing was available
- large migration or upgrade
- unexpected mismatch between saved page text and workspace search results
