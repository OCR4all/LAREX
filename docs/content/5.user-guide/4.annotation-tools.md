# Annotation Tools

LAREX annotations are built from three element types:

- Regions
- Textlines
- Baselines

## Drawing Tools

| Tool | Shortcut | Notes |
|------|----------|-------|
| Select | `V` | Select/edit existing elements |
| Move | `G` | Move selected element(s) |
| Region (Polygon) | `P` | Draw polygon region |
| Region (Rectangle) | `R` | Draw rectangular region |
| Textline (Polygon) | `T` | Draw polygon textline |
| Textline (Rectangle) | `Shift + T` | Draw rectangular textline |
| Baseline | `B` | Draw polyline baseline |
| Cut Line | `C` | Cut using a polyline |
| Cut Polygon | `Shift + C` | Cut using a polygon |
| Cut Rectangle | `Alt + C` | Cut using a rectangle |

## View Modes and Auto-Parenting

The view mode affects creation behavior:

- `Default` (`1`): standard hierarchical editing
- `Textline` (`2`): textline creation can auto-create/find parent regions
- `Baseline` (`3`): baseline creation can auto-create/find parent textline/region context

## Drawing Behavior

### Polygon and Polyline Modes

- Click to add points.
- Double-click to finish.

### Rectangle Modes

- First click starts rectangle.
- Second click completes rectangle.

### Cut Modes

- Cut line/polygon: click to add points, double-click to apply cut.
- Cut rectangle: first click starts, second click applies cut.

## Selection and Navigation

| Action | Behavior |
|--------|----------|
| Click | Select element |
| `Shift + Click` | Toggle item in multi-selection |
| `Shift + Drag` | Marquee multi-selection |
| `Tab` / `Shift + Tab` | Navigate next/previous selectable element |
| `Arrow Down` / `Arrow Up` | Navigate next/previous selectable element |
| `Ctrl/Cmd + A` | Select all selectable polygons |
| `Esc` | Cancel active drawing or clear selection |

## Editing

### Geometry Editing

- Drag polygon or baseline nodes to reshape.
- Click near an edge/segment to insert a new node, then drag it.
- Parent/image constraints are enforced when enabled.

### Structure Operations

From the **Structure** panel:

- Delete selected
- Hide selected
- Show selected

### Merge

- `M` merges selected elements when they are compatible (same type).

### Delete

- `Delete` or `Backspace` removes selected elements.

## Undo/Redo

| Action | Shortcut |
|--------|----------|
| Undo | `Ctrl/Cmd + Z` |
| Redo | `Ctrl/Cmd + Shift + Z` or `Ctrl/Cmd + Y` |
