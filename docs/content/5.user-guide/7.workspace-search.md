# Workspace Search

Workspace search helps teams find transcription text across projects and pages. It is designed for review, correction, and navigation, not just discovery.

## What Search Covers

Search works on indexed text derived from project PAGE XML and related text-index settings. Results are scoped to the selected workspace and the user's permissions.

Use it to:

- find a word or phrase across projects
- inspect repeated OCR/HTR errors
- jump from a result to the relevant page
- review text after normalization or dictionary changes
- identify pages that need correction

## Run A Search

1. Open the command center or the workspace search page.
2. Enter the query.
3. Review grouped results.
4. Open a matching page when you need context.

When a result opens in the editor, LAREX can switch to text mode and apply the search term as a text filter so the relevant hit is visible immediately.

## Search Quality

Search quality depends on the available PAGE XML and indexing state. A page with no XML, empty text, or pending indexing may not appear as expected.

If a page was just edited or imported from an Action, wait for the index state to refresh before assuming search is missing data.

## Review Patterns

| Goal | Pattern |
| --- | --- |
| Correct recurring OCR errors | Search for the suspected form, open results, correct in text mode. |
| Check a normalized form | Search before and after applying normalization or review workflows. |
| Audit a collection term | Search the workspace, then filter by project or page metadata. |
| Continue interrupted review | Search for known text and jump directly back to the page. |
