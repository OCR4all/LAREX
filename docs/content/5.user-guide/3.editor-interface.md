# Editor Interface

The editor is where page images and PAGE XML become reviewable, editable project data. It combines page navigation, a canvas, annotation tools, text review, metadata, validation helpers, and processor entry points.

## Layout

```text
Left sidebar  |  Center tabs and canvas  |  Right sidebar
Project/page  |  page image + overlays   |  metadata, structure,
navigation    |  text and layout modes   |  tasks, settings
```

The center area uses tabs for projects and pages. The left sidebar is for navigation and filtering. The right sidebar is for work on the active page.

## Left Sidebar

Use the left sidebar to:

- return to the dashboard
- open the command center
- filter page names
- apply advanced page filters
- choose the default image variant
- browse opened projects and pages
- access the user menu

The sidebar can be collapsed and resized.

## Center Canvas

The canvas displays the active page image and PAGE XML overlays. In layout mode, it is optimized for region, textline, baseline, reading-order, relation, and metadata work. In text mode, it focuses on transcription review and token-level correction.

Mouse behavior:

| Interaction | Result |
| --- | --- |
| Wheel | Zoom |
| Drag empty space | Pan when no shape edit is active |
| Click | Select or edit according to the active tool |
| Double-click | Finish polygon or polyline drawing |

## Toolbar

The toolbar can float or dock to the top, bottom, left, or right.

The combined mode-and-view selector is at the end of the toolbar. Its trigger shows the complete active state, such as **Layout · Hierarchy** or **Text · Canvas**. Open it to choose from two groups:

- Layout views: **Hierarchy**, **Text lines**, and **Baselines**
- Text views: **Canvas** for focused correction on the page image and **List** for searchable, sortable textline review

Use `1`–`5` to select these five entries in order: Layout · Hierarchy, Layout · Text lines, Layout · Baselines, Text · Canvas, and Text · List.

Main tool groups:

- select and move
- draw regions, textlines, and baselines
- cut, merge, and edit shapes
- choose the active mode and view from one grouped selector
- undo, redo, and history
- open keyboard shortcuts
- pick an Action target with the wand tool

Use `?` to open the shortcut dialog.

## Right Sidebar

The right sidebar contains the working panels for the active page.

Layout mode panels:

- structure
- reading order
- relations
- metadata
- tasks
- heatmap
- settings

Text mode panels:

- metadata
- tasks
- settings
- codec
- dictionary
- diff
- filter

Header actions include save, version history, save and complete for task workflows, XML access, and relevant validation/resource actions.

## Save Before Processing

LAREX Actions process saved PAGE XML. If you select a page, region, or textline in the editor and there are unsaved changes, LAREX asks whether to save before dispatching the Action.

If saving fails, the Action is not started. This prevents processors from reading stale or inconsistent PAGE XML.

## Pick Action Targets

Use the wand tool or context menu to run processors on editor targets:

| Target | What the processor receives |
| --- | --- |
| Page | Full selected page scope. |
| Region | Full page files plus selected region IDs. |
| Textline | Full page files plus selected textline IDs. |

Processors receive full page images/XML according to their Action definition. The target metadata tells the processor which region or textline the user selected.
