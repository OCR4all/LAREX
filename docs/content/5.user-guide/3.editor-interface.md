# Editor Interface

The editor has three main areas: left sidebar, center canvas/tab area, and right sidebar.

## Overview

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Left Sidebar        │ Center (Dockview project/page tabs + canvas) │ Right │
│ (projects/pages)    │                                             │ Sidebar │
│                     │                                             │ (metadata,
│                     │                                             │ structure,
│                     │                                             │ reading order,
│                     │                                             │ tasks, settings)
└──────────────────────────────────────────────────────────────────────────────┘
```

`Metadata` is in the **right** sidebar (not the left).

## Left Sidebar

The left sidebar is navigation-focused.

### Contains

- Dashboard/logo menu
- Command center button (`Ctrl/Cmd + K`)
- Page name filter
- Advanced page filter popover
- Default image variant selector
- Opened projects with page lists
- User menu

### Behavior

- Can be collapsed/expanded
- Width is resizable
- In collapsed mode, projects/pages can still be expanded in compact form

## Center Area

The center uses Dockview tabs:

- Project tabs
- Page tabs (annotation canvases)

When no page is open, an empty-state panel is shown.

## Toolbar

The toolbar can be:

- Floating
- Docked top
- Docked bottom
- Docked left
- Docked right

### Main Controls

- Selection/move
- Region drawing (polygon/rectangle)
- Textline drawing (polygon/rectangle)
- Baseline drawing
- Cut tools (line/polygon/rectangle)
- Merge
- View mode tabs (`Default`, `Textline`, `Baseline`)
- Undo/redo/history
- Layout/Text mode switch
- Toolbar compact mode toggle
- Keyboard shortcuts dialog entry

## Right Sidebar

The right sidebar contains editor panels and primary page actions.

### Header Actions

- Save
- Version history
- Save + Complete (when open subtasks exist)
- Additional actions menu (for example codec and dictionary checks)

### Layout Mode Panels

- Structure
- Reading Order
- Metadata
- Tasks
- Heatmap
- Settings

### Text Mode Panels

- Metadata
- Tasks
- Settings
- Codec
- Dictionary
- Diff
- Filter

### Behavior

- Can be collapsed/expanded
- Width is resizable
- Panels are accordion-based in expanded mode and popover-based in collapsed mode

## Canvas Interaction

### Mouse

- Wheel: zoom
- Drag: pan (when not dragging/editing shapes)
- Click: select/edit based on active mode
- Double-click: finish polygon/polyline drawing modes

### Keyboard Help

- `?` opens/closes the keyboard shortcuts dialog.
- Full reference: [Keyboard Shortcuts](/user-guide/keyboard-shortcuts)

## Saving

- Manual save is available via the right sidebar save action and `Ctrl/Cmd + S`.
- Version history is available from the right sidebar.

## Workspace Search Integration

Pages opened from workspace text search open directly in:

- `Text` mode
- `Textline` text view

The search term is also applied to the editor text filter so the relevant hit can be reviewed immediately after navigation.

## Dictionary Integration

When a project has an assigned dictionary, text mode can:

- mark tokens that are not present in the dictionary
- show closest-match suggestions
- open the dictionary in a slideover browser
- replace a token with a suggested dictionary entry

If the dictionary is editable and not locked, owner/curator workflows can also add tokens from the editor.
