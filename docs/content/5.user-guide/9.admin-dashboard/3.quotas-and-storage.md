# Quotas and Storage

Storage controls are split between **Admin -> Quotas** and **Admin -> Storage**. Quotas decide how much each workspace may store. Storage cleanup helps remove files that are no longer referenced by database records.

## Quota Overview

Open **Admin -> Quotas** to see every workspace quota entry. The page shows:

- total workspaces
- quota-exceeded workspaces
- custom quota count
- default quota size
- current usage and usage percentage
- whether a workspace uses a custom or default quota

Use the search field to find a workspace by name or ID. Filter by quota status or quota type to focus on exceeded or custom entries.

## Increase A Workspace Quota

1. Open **Admin -> Quotas**.
2. Find the workspace.
3. Open the row actions menu.
4. Select **Edit Quota**.
5. Choose a preset size or enter a quota in GB.
6. Keep **Mark as custom quota** enabled if this workspace should not follow the default.
7. Save.

Increasing quota immediately allows new uploads, server-side imports, and Action result imports to continue once the workspace is no longer over limit.

## Recalculate Usage

Use **Recalculate Usage** when the displayed usage looks stale after imports, cleanup, failed uploads, or operational maintenance. LAREX recalculates storage usage for that workspace and refreshes the quota table.

## Reset Quotas

| Reset action | Effect |
| --- | --- |
| Reset to Default | Sets one workspace back to the current default quota and clears its custom flag. |
| Reset All to Default | Resets all non-custom quotas to the default quota value. |

Use custom quotas for exceptions that should survive default resets.

## Storage Cleanup Overview

Open **Admin -> Storage** to review storage health and orphaned files. The page summarizes:

- total storage used
- image, XML, and thumbnail counts known to the database
- orphaned images
- orphaned XML files
- orphaned thumbnails
- temporary files
- total orphaned size

Orphaned files are files on disk that LAREX does not consider linked to current database records.

## Delete Orphaned Files

1. Open **Admin -> Storage**.
2. Filter by file path or type if needed.
3. Select individual files, delete one row, or use **Delete All Orphaned**.
4. Review the deletion result: deleted count, failed count, and freed storage.

Bulk deletion is an operational maintenance action. Prefer filtering and selected deletion when investigating a specific import, upload, or cleanup issue.

## Quota And Import Relationship

Server-side import checks available workspace quota during scan. If the scan reports that quota is exceeded, the import cannot start. Free storage or increase quota before retrying the import.
