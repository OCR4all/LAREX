# Dictionaries

Dictionaries help reviewers spot tokens that are unexpected for a project. They are most useful when a workspace needs consistent transcription review across many pages.

## What Dictionaries Do

When a project has an assigned dictionary, text mode can:

- mark tokens that are not present in the dictionary
- show closest-match suggestions
- let users browse dictionary entries
- replace a token with a suggested entry
- add tokens when the dictionary is editable and the user's role allows it

A dictionary is a review aid, not an automatic proof that text is correct.

## Create A Dictionary

1. Open **Dictionaries** from the toolkit.
2. Create a dictionary with a clear name.
3. Add entries manually or import a prepared list when supported by the current UI.
4. Assign the dictionary to a workspace preset or project.
5. Ask reviewers to use text mode dictionary panels during correction.

Keep dictionaries project-specific enough to be helpful. A dictionary that accepts every possible token will hide useful warnings.

## Review In Text Mode

In the editor, use the dictionary panel to inspect flagged tokens. For each token:

1. Compare the token to the page image.
2. Accept the current token if it is correct for the source.
3. Replace it with a suggestion if the OCR/HTR output is wrong.
4. Add it to the dictionary only when the token should be accepted elsewhere.

## Maintain Dictionaries

Curators should periodically review additions. Temporary, uncertain, or source-specific forms can reduce dictionary value if they are added without a policy.

Consider separate dictionaries when projects differ by language, period, script, or editorial convention.
